# KHALA · AI 문서 검증 테스트

## 0. 시작하기

앱: http://127.0.0.1:3000 — 관리자 계정을 만든 뒤 모델 설정에서 API 연결 테스트를 통과하세요. `docs/account-model-guide.md`를 참고하세요. 김지우(업무 사용자), 이서윤·박도현(리뷰어)을 가입·승인하고 김지우→이서윤, 이서윤→박도현 순으로 담당 리뷰어를 지정하세요. 이름 전환은 로그아웃·로그인으로 진행하며 동시 테스트에는 별도 브라우저 프로필을 사용하세요.

**PDF 업로드 → LLM이 문서 검증 → 사람이 결과 검토 → 리뷰 피드백을 LLM이 검증 기준에 반영 → 수정 PDF를 새 기준으로 LLM이 재검증 → 최종 승인** 순서입니다. 검증 카드의 근거와 판정을 처음부터 사람이 채울 필요가 없습니다.

- 신규 테스트를 시작할 때 문서가 0개, 시장조사와 일반 문서가 각각 v1인지 확인합니다. 이미 진행한 데이터가 있다면 마지막 절의 초기화 방법을 사용합니다.
- PDF 7개는 모두 가상 자료이며 1쪽입니다. 샘플을 번호 순서대로 사용하고 피드백 버튼은 한 번만 누릅니다.
- 업로드 후 AI 검증이 끝날 때까지 기다립니다. 상단 요약과 오른쪽의 검토한 주장·원문 근거·판단 이유·수정 제안이 결과입니다. 검증 완료는 모든 항목이 충족이라는 뜻이 아닙니다.
- AI가 추출된 PDF 텍스트를 페이지별로 읽고 업무별 검증 기준를 적용합니다. 이 내용과 피드백이 설정한 API 모델로 전달됩니다.
- 외부 웹 출처의 진위 확인, 스캔 PDF OCR, PDF 파일 자동 수정은 아직 포함되지 않습니다. 근거가 부족하면 미확인으로 남깁니다. PDF 안에 제시된 근거와 주장·산식은 LLM이 대조합니다.
- AI 제목·표현·카드 개수는 매번 같지 않을 수 있습니다. 아래 오류를 이해했는지와 검증 동작을 확인하세요. 결과가 기대와 다르면 억지로 충족 처리하지 말고 이유를 검토합니다.

## 1. 테스트 지도

| 흐름 | 작성자 / 리뷰어 | PDF | 확인할 AI 동작 |
| --- | --- | --- | --- |
| A. 직원 보고서 | 김지우 / 이서윤 | 01 → 02 교체 | 국내·글로벌 오류 발견, 시장조사 v2로 수정본 재검증 |
| B. 상사 자기 작업 | 이서윤 / 박도현 | 03 → 04 교체 | 매출액·거래액 오류 발견, 자기 경험으로 시장조사 v3 발행 |
| B+. 새 보고서 | 김지우 / 이서윤 | 05 새 업로드 | 시장조사 v3의 기준을 처음부터 적용 |
| C. 일반 문서 | 김지우 / 이서윤 | 06 → 07 교체 | 비율·조사 대상 오류 발견, 일반 문서 v2만 발행 |

**v1에서도 LLM이 오류를 발견할 수 있습니다.** 피드백 학습의 의미는 오류를 처음 발견할 능력을 켜는 것이 아니라, 조직이 중요하게 보는 기준을 공용 검증 기준에 명시해 이후 문서에서 별도로 반복 검증하게 만드는 것입니다.

## 2. A - 직원 보고서에서 시장 범위를 학습

1. **김지우 → 내 문서**에서 `01-market-scope-error.pdf` 선택 → 업무 유형 **시장조사 보고서** → **PDF 검증 시작**.
2. AI 결과를 기다립니다. v1 상태에서도 국내 매출액과 글로벌 매출액의 비교가 잘못됐다는 지적이 요약 또는 카드에 있어야 합니다. 인용 근거가 실제 1쪽 A/B 원문과 일치하는지 봅니다. 성장률의 수학적 계산이 50%여도 비교 대상이 달라 문제가 있다는 설명이 중요합니다.
3. 기본 화면은 확인이 필요한 항목만 보여줍니다. 충족 결과는 **충족** 또는 **전체** 필터로 봅니다. 카드들을 수동으로 충족시키지 않고 **리뷰 요청**을 누릅니다. 미확인·불충족이어도 리뷰 요청은 가능합니다.
4. **이서윤 → 리뷰 대기열**에서 문서를 엽니다. AI가 지적한 미해결 항목 때문에 최종 승인은 막혀야 합니다. **박도현**은 이 문서 담당이 아니므로 해당 문서를 볼 수 없어야 합니다.
5. 이서윤으로 **검증 결과**의 문제 카드에서 **이 내용으로 수정 요청**을 누릅니다. 피드백과 근거가 자동 입력돼 있으니 필요한 부분만 고치고 **수정 요청 보내기**를 누릅니다. 직접 입력하려면 **직접 피드백 쓰기**를 누르고 아래 예시를 사용하세요.

{{A}}

**기대 결과:** 문서는 수정 요청, 피드백에는 시장조사 v2와 변경 요약이 표시됩니다. **업무별 검증 기준 → 시장조사 → v2**에서 두 출처의 시장 범위와 원문 근거를 비교하는 기준이 생깁니다. 문서 자체는 수정 전이므로 v1을 유지합니다.

6. **김지우 → 기존 01 문서**의 상단 **수정본 업로드** 또는 **수정본 선택**에서 `02-market-scope-fixed.pdf`를 넣습니다. ‘내 문서’의 신규 업로드를 쓰면 다른 문서가 되므로 반드시 교체를 사용합니다.
7. LLM이 v2로 수정본을 자동 검증합니다. 국내 매출액 1,200억 원과 1,680억 원, 누적 변화율 40%가 서로 맞는지 판단해야 합니다. 새 시장 범위 기준과 리뷰 수정사항도 함께 검사합니다.
8. AI가 채운 각 카드의 근거와 판단을 읽습니다. 모든 필수 항목이 충족이면 **리뷰 요청 → 이서윤 → 최종 승인**. 미확인이 남으면 필요한 근거를 확인하고 **판정 정정**에서 이유를 기록합니다. 문서가 잘못됐다면 PDF를 먼저 수정합니다.
9. **검증 기록**에서 원본과 수정본을 비교합니다. 원본은 50%/v1과 당시 AI 결과, 수정본은 40%/v2와 새 AI 결과가 남아야 합니다. **원본 저장**은 선택한 개정본 PDF를 내려받습니다.

판정을 정정해야 할 때 참고할 실제 근거: `1쪽 A 표 2는 2023년 국내 매출액 1,200억 원, B 표 4는 2025년 국내 매출액 1,680억 원입니다. 같은 시장·지표·단위이며 (1,680-1,200)/1,200×100=40%입니다.` 자동 결과가 맞으면 다시 입력할 필요가 없습니다.

## 3. B - 상사 자신의 작업 경험도 학습

1. **이서윤 → 내 문서**에서 `03-reviewer-metric-error.pdf`를 **시장조사 보고서**로 새 업로드합니다. 시장조사 v2를 상속받고 LLM이 검증합니다.
2. 국내라는 범위는 같지만 A 매출액과 B 거래액을 비교했다는 오류가 나타나야 합니다. 기존 시장 범위 규칙만으로는 충분하지 않다는 사례입니다.
3. 리뷰 요청 전에 문제 카드의 **이 경험을 검증 기준에 반영**을 누릅니다. 내용과 근거가 미리 채워지므로 필요한 부분만 고치고 **검증 기준에 반영**을 누릅니다. 새로 적으려면 **직접 경험 쓰기**에서 아래 예시를 사용할 수 있습니다.

{{B}}

**기대 결과:** 다른 사람에게 리뷰를 받지 않고도 자신의 작업 경험이 시장조사 v3로 발행됩니다. 기존 시장 범위 기준은 유지되고 지표 정의 비교가 추가 또는 통합됩니다. PDF 업로드 자체가 공용 검증 기준를 자동 변경하지는 않습니다. 검증 결과에서 얻은 경험을 이 기능으로 등록해야 합니다.

4. 같은 문서에서 `04-reviewer-metric-fixed.pdf`로 교체합니다. LLM이 v3로 다시 읽고, 국내 매출액 1,200억 원 → 1,560억 원의 누적 변화율 30%와 수정사항을 검증해야 합니다.
5. 결과를 검토하고 **리뷰 요청**. 이서윤은 자신의 문서를 최종 승인할 수 없어야 합니다. **박도현 → 리뷰 대기열**에서 이 문서를 열어 모든 필수 항목이 충족이면 최종 승인합니다.

## 4. B+ - 새 문서에 v3가 바로 적용

1. **김지우 → 내 문서**에서 `05-market-new-document.pdf`를 **시장조사 보고서**로 새 업로드합니다.
2. 처음부터 v3가 표시되고 LLM이 시장 범위·지표 정의 기준을 함께 적용해야 합니다. 이 문서에는 별도 피드백이 없어도 됩니다.
3. 두 출처가 모두 국내 B2B SaaS 매출액이며 1,200억 원 → 1,800억 원, 누적 변화율 50%입니다. AI가 이를 근거와 함께 판단하는지 봅니다.
4. **업무별 검증 기준**에서 v1/v2/v3의 변경 요약과 검증 기준의 적용 조건·판정 기준·확인 방법를 비교합니다. PDF 자동 반영에는 ‘검증 기준 개선함’의 수동 발행 절차가 필요하지 않습니다.
5. 모든 필수 결과가 충족이면 김지우가 리뷰 요청, 이서윤이 최종 승인합니다.

## 5. C - 일반 문서는 독립된 기준으로 검증

1. **김지우 → 내 문서**에서 `06-general-survey-error.pdf` 선택 → **일반 문서** → 업로드합니다.
2. 일반 문서 v1로 LLM이 검증합니다. 시장조사 전용 비교·성장률 카드는 없어야 합니다. 대상자 20명/응답자 10명/만족 7명인데 전체 참여자 90% 또는 전사 대부분이 만족한다고 주장한 오류를 찾아야 합니다.
3. **리뷰 요청 → 이서윤 → 해당 문서**의 문제 카드에서 **이 내용으로 수정 요청**을 누르고, 내용을 확인한 뒤 **수정 요청 보내기**를 누릅니다. 아래는 직접 쓸 때 참고할 예시입니다.

{{C}}

**기대 결과:** 일반 문서 v2가 생기며 비율의 분모와 조사 대상에 맞춰 주장을 검증하는 기준이 반영됩니다. 시장조사는 v3 그대로입니다.

4. **김지우 → 기존 06 문서 → 수정본 업로드**에서 `07-general-survey-fixed.pdf`를 선택하고 **이 PDF로 교체하고 검증**을 누릅니다.

6. 모든 필수 결과를 검토한 뒤 김지우가 제출, 이서윤이 최종 승인합니다.

## 6. 추가 확인과 실패 복구

- **간편 입력:** 피드백은 한 칸에 문제와 수정 방향을 함께 적습니다. 근거는 자동 첨부되며 **첨부 근거**를 펼쳐 수정할 수 있습니다.
- **초안 유지:** 입력창을 닫거나 새로고침해도 같은 문서·개정본·페이지·사용자의 초안이 이 브라우저 탭에 남습니다. **나중에 계속**으로 닫았다가 같은 카드에서 다시 열면 이어 쓸 수 있습니다. 성공적으로 전송하면 초안은 지워집니다.
- **키보드:** Ctrl+Enter로 전송하고 Esc로 닫을 수 있습니다. 보내는 동안에는 닫기와 중복 전송이 막힙니다.
- **수정 요청 없이 의견만 남기기:** 입력창에서 **작성자에게 수정 요청하기**를 끄면 문서를 리뷰 중 상태로 유지하며 피드백과 검증 기준 반영만 진행합니다. 여러 항목을 순서대로 검토할 때 활용하세요.
- **검토 화면:** 오른쪽의 **검증 결과 / 피드백 / 검증 기준**으로 전환합니다. 긴 인용문은 **원문 근거 · 적용 기준 보기**에서 확인하고 페이지 이동 링크로 원문을 찾아갑니다.

- **AI 검증 실패:** PDF 등록은 유지됩니다. 결과 상단에 실패 이유가 나오고 최종 승인이 막힙니다. 연결이나 입력 문서 문제를 해결한 뒤 **AI 문서 검증 실행**으로 재시도합니다. 같은 PDF를 중복 업로드할 필요가 없습니다.
- **기존 문서:** 이전에 업로드한 PDF는 **AI 문서 검증 실행** 버튼으로 검증할 수 있습니다. 자동으로 과거 문서를 일괄 재검증하지 않습니다.
- **다시 검증:** **AI 다시 검증**은 현재 PDF와 현재 적용 검증 기준로 새 결과를 생성합니다. 수동 정정도 새 결과로 교체되며 과거 기록은 유지됩니다. 최신 공용 검증 기준가 자동으로 기존 문서에 소급 적용되지는 않습니다.
- **근거 일치 검사:** 서버는 AI가 인용한 문장이 해당 PDF 페이지에 있는지 확인합니다. 일치하지 않으면 그 카드가 미확인으로 남습니다. 페이지 이미지의 문구와 카드 인용을 직접 비교해 보세요.
- **성장률 대기:** 출처·비교 조건 중 하나라도 미확인/불충족이면 성장률은 통과되지 않습니다. 사람이 선행 조건을 불충족으로 바꾸면 기존 성장률 판정도 재확인 필요가 됩니다.
- **사람의 정정:** AI가 틀렸거나 추가 근거를 확인했다면 카드의 **판정 정정**에서 기록합니다. AI 판정과 사람 판정은 구별되며 원래 AI 판단도 펼쳐 볼 수 있습니다.
- **피드백 정리 실패:** 피드백은 저장되고 새 검증 기준 발행은 보류됩니다. 담당 리뷰어가 **피드백** 패널의 **AI 검증 기준 반영 다시 시도**으로 재시도합니다. 정리가 끝나기 전 수정 PDF 교체는 막힙니다.
- **입력 한계:** 현재 텍스트 기반 검증입니다. 텍스트가 없는 스캔 문서는 검증 실패로 표시됩니다. 추출 텍스트가 페이지당 12,000자, 문서 전체 120,000자를 넘거나 후보 검증 카드가 300개를 넘으면 나눠 업로드하도록 안내합니다.
- **승인 정책:** AI 검증 완료와 모든 필수 항목 충족이 필요하며 최종 승인은 담당 리뷰어가 합니다. AI가 문서를 승인하거나 조직 검증 기준를 피드백 없이 바꾸지는 않습니다.

## 7. 완료 체크와 초기화

- [ ] 업로드 직후 사람 입력 없이 AI 근거·판정·수정 제안이 생성된다.
- [ ] 01의 시장 범위, 03의 지표 정의, 06의 비율·조사 대상 오류를 지적한다.
- [ ] 02/04/07 수정본은 새 검증 기준로 다시 검증한다.
- [ ] 상사 자신의 경험도 검증 기준에 반영되고 새 문서가 이를 상속한다.
- [ ] 시장조사 v3와 일반 문서 v2가 독립적으로 관리된다.
- [ ] 미확인·불충족 상태는 최종 승인할 수 없다.
- [ ] 과거 PDF·AI 결과·수동 판정·검증 기준 버전이 검증 기록에 남는다.
